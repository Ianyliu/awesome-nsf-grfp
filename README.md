## 🚀 Start Here

If you are new to the GRFP, a simple workflow is:

**1. Read the current NSF rules → 2. Study several successful examples → 3. Draft around Intellectual Merit and Broader Impacts → 4. Get feedback → 5. Re-check formatting and eligibility before submission.**

This repository is strongest as a **comparative library**: the goal is not to discover one “perfect” essay, but to see how different applicants communicate a coherent research trajectory and future impact.

## ✅ How to Use This Repository

A productive way to use these resources is to compare several successful applications rather than imitate a single one.

1. **Read for structure first.** Identify how applicants frame the problem, motivation, methods, intellectual merit, and broader impacts.
2. **Compare multiple examples.** Successful essays differ substantially by discipline and applicant background.
3. **Extract patterns, not prose.** Notice what information reviewers receive and when they receive it.
4. **Draft in your own voice.** Your application should reflect your own research direction, trajectory, and broader-impact goals.
5. **Check current NSF rules.** Eligibility, solicitation language, formatting, and review expectations can change between cycles.

> [!IMPORTANT]
> This repository is an unofficial community resource and is not affiliated with or endorsed by the National Science Foundation. Official NSF materials should always take precedence when requirements differ.
